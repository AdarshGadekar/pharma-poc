# AI-Powered Forecasting Setup

This application includes AI-powered predictive analytics using OpenAI's GPT-4 Turbo model.

## Features

### 1. Patient Outcome Prediction
- Predicts treatment outcomes (Excellent/Good/Fair/Poor)
- Provides confidence scores and risk assessments
- Identifies key predictive factors
- Generates clinical recommendations
- Estimates time to remission

### 2. Drug Efficacy Forecasting
- Projects 3-year and 5-year response rates
- Analyzes efficacy trends
- Provides confidence intervals
- Generates market projections

### 3. Biomarker Insights
- Assesses clinical significance
- Evaluates predictive accuracy
- Identifies future applications
- Provides cost-benefit analysis

## Setup Instructions

### Option 1: Use Real AI (OpenAI GPT-4)

1. **Get an OpenAI API Key**
   - Go to [platform.openai.com](https://platform.openai.com/)
   - Sign up or log in
   - Navigate to API Keys section
   - Create a new API key
   - Copy the key (starts with `sk-`)

2. **Create Environment File**
   ```bash
   cp .env.example .env
   ```

3. **Add Your API Key**
   Edit `.env` file:
   ```
   VITE_OPENAI_API_KEY=sk-your-actual-api-key-here
   ```

4. **Restart Development Server**
   ```bash
   npm run dev
   ```

### Option 2: Use Simulated AI (No API Key Required)

If you don't add an API key, the application will use simulated AI predictions that are:
- Clinically realistic
- Based on patient data patterns
- Instant (no API calls)
- Free to use

The UI will indicate "Simulated AI Analysis" instead of "Generated by GPT-4 Turbo"

## How It Works

### Patient Outcome Prediction

The AI analyzes:
- Patient demographics (age, gender)
- Disease characteristics (condition, stage)
- Treatment regimen
- Clinical metrics trends (last 3 months)
- Biomarker profiles
- Current treatment status

Returns:
```json
{
  "predictedOutcome": "Excellent",
  "confidenceScore": 87,
  "keyFactors": [
    "Positive biomarker response trend",
    "Good treatment adherence",
    "Minimal adverse events"
  ],
  "recommendations": [
    "Continue current treatment regimen",
    "Monitor biomarkers monthly"
  ],
  "riskAssessment": "Low",
  "estimatedTimeToRemission": "4-8 months"
}
```

### Drug Efficacy Forecasting

Analyzes historical response rates to predict future efficacy:

- Market dynamics consideration

### Biomarker Insights

## Troubleshooting

### "AI analyzing patient data..." shows indefinitely
- Check your API key is correct
- Verify you have OpenAI credits
- Check browser console for errors
- Application will fall back to simulated predictions after timeout

### API Key Not Working
```bash
# Verify your .env file exists
ls -la .env

# Check the key format (should start with sk-)
cat .env

# Restart the dev server
npm run dev
```

### Rate Limit Errors
- OpenAI has rate limits based on your account tier
- Free tier: 3 requests/minute
- Paid tier: Higher limits
- Application will queue requests automatically

## Disabling AI Features

To disable AI and use only simulated predictions:
1. Remove or comment out `VITE_OPENAI_API_KEY` in `.env`
2. Restart the server

The application will work identically but show "Simulated AI Analysis"
