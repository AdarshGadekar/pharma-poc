# Where to Find AI Predictions

## Location: Patient Journeys Tab

### Step-by-Step:

1. **Navigate to Patient Journeys**
   - Click the "Patient Journeys" tab in the top navigation
   - It's the second tab from the left

2. **Select a Patient**
   - You'll see 4 patient cards at the top
   - Click on any patient (PT-2847-A, PT-1923-B, PT-3156-C, or PT-1654-D)

3. **Scroll Down to AI Prediction Section**
   - After the patient profile cards
   - After the "Patient Story" section
   - You'll see a section titled **"AI-Powered Outcome Prediction"**

## What You'll See in the Prediction Panel:

### Header
- **Title**: "AI-Powered Outcome Prediction"
- **Subtitle**: "Simulated AI Analysis" (or "Generated by GPT-4 Turbo" if API key is configured)
- **Badges**: "AI Analysis" and confidence percentage

### Three Main Metrics (Top Row):

1. **Predicted Outcome**
   - Shows: Excellent / Good / Fair / Poor
   - Color-coded based on outcome
   - Based on current treatment trajectory

2. **Risk Assessment**
   - Shows: Low / Moderate / High
   - Indicates progression risk level
   - Color-coded by risk level

3. **Time to Remission**
   - Shows: Estimated timeline (e.g., "4-8 months")
   - Predicted time until clinical remission

### Two Detail Sections (Bottom Row):

1. **Key Predictive Factors**
   - Lists 3 main factors influencing the prediction
   - Examples:
     - "Positive biomarker response trend"
     - "Good treatment adherence"
     - "Minimal adverse events"

2. **AI Recommendations**
   - Lists 2-3 clinical recommendations
   - Examples:
     - "Continue current treatment regimen"
     - "Monitor biomarkers monthly"
     - "Consider dose optimization if response plateaus"

### Footer Note
- Explains the prediction methodology
- Shows confidence score
- Disclaimer about using as decision support tool

## Visual Identification:

The AI Prediction Panel has:
- **Gray/slate background** (toned down from purple)
- **"AI-Powered Outcome Prediction" heading**
- **Sparkles icon** (✨) next to the title
- **Brain icon** in the AI Analysis badge
- **Three metric cards** in a row
- **Two recommendation sections** below

## Technical Details:

- **Component**: `AIPredictionPanel.jsx`
- **Service**: `src/services/aiForecasting.js`
- **Mode**: Simulated AI (no API key required)
- **Updates**: Real-time when switching patients
- **Data**: Based on patient timeline, biomarkers, and treatment response

## To Enable Real GPT-4 Predictions:

1. Create `.env` file in project root
2. Add: `VITE_OPENAI_API_KEY=sk-your-key-here`
3. Restart dev server: `npm run dev`
4. Badge will change to "Generated by GPT-4 Turbo"
