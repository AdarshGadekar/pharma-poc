# Jazz Pharma Demo - Screenshot Capture Guide

## 📸 How to Capture Screenshots

**Recommended approach:** Capture specific UI sections, not full pages

**Tools:**
- Browser screenshot tool (Ctrl+Shift+S in Firefox, or browser extensions)
- Snipping tool / Screenshot tool on your OS
- Crop to show only the relevant section

## 🎯 Quick Capture Checklist

**Before you start:**
- [ ] Open the app in browser
- [ ] Set browser zoom to 100%
- [ ] Clear any notifications or popups
- [ ] Have screenshot tool ready

**For each screenshot:**
- [ ] Navigate to correct tab
- [ ] Select correct patient/drug/biomarker if needed
- [ ] Scroll to the specific section
- [ ] Capture ONLY that section (not full page)
- [ ] Crop tightly with small padding
- [ ] Save with descriptive filename
- [ ] Verify text is readable

**Total screenshots needed:** 26 (minimum 20 for complete demo)

**Estimated time:** 30-45 minutes to capture all screenshots
